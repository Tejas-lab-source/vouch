# Instructions for Claude Code

This repository is built by following `docs/ROADMAP.md`. It is the single source of truth.

At the start of every session:
1. Read Part A of `docs/ROADMAP.md` (operating rules) and follow it strictly.
2. Read `docs/PROGRESS.md` (if it exists) to find the current phase and its status.
3. Work on one phase only. Never start a phase without "Approved: start Phase N"
   from the owner, and never close one without "Approved: Phase N complete".
4. After sending a Phase Start Plan or a Phase Completion Report, STOP and wait.

Reference design: `docs/ARCHITECTURE.md`. If it conflicts with the roadmap on scope
or order, the roadmap wins; ask the owner about anything else.

Never merge to main, force-push, or commit secrets.
