# @vouch/api-client

The typed HTTP client for every client app.

- `src/generated.js` is generated by `pnpm contracts:generate` (never edit it by hand). It holds
  one plain fetch function per endpoint in `@vouch/contracts`, with metadata only. Types come
  from JSDoc, so no zod reaches the bundle. `pnpm contracts:check` fails when it is stale.
- `createApiClient` handles:
  - the base URL and `X-App-Version`
  - an automatic `Idempotency-Key` for idempotent endpoints
  - the error envelope, mapped to `ApiError` (`code`, `status`, `details`)
  - a single-flight refresh on 401 (concurrent 401s share one refresh)
- `createSession({ transport })` keeps the access token in memory:
  - `'cookie'` (web): the refresh token is the httpOnly cookie.
  - `'body'` (mobile): the refresh token lives in the given `storage` (the secure store).
- `createSessionClient` binds a client to a session. A refused refresh ends the session.
- `keys` holds the TanStack Query key factories, used for cache entries and invalidation.
